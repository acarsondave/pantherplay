# Design System

## Philosophy
"The Gym, not a School."
PantherPlay focuses on low-friction, repetitive practice for muscle memory. The interface must be premium, elegant, clean, and highly customizable. 

## Tokens
- **Themes**: Currently supporting Catppuccin Mocha, but extending to a robust, user-selectable theme system.
- **Typography**: Moving away from generic sans-serif to customizable, premium fonts (e.g. JetBrains Mono, Inter, and custom Google Fonts).
- **Radius & Spacing**: Generous padding, smooth corner radii.
- **Micro-interactions**: Hover states, smooth transitions, and tactile feedback.
