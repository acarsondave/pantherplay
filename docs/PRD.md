# Product Requirements Document (PRD)

**Product Name:** PantherPlay
**Goal:** Create a "MonkeyType for Guitar" – a low-friction, highly aesthetic practice tool to build muscle memory.

## Core Requirements
- Real-time chord detection via Rust/Tauri backend.
- Zero-friction start (no enforced login).
- Premium, customizable UI (themes, fonts).
- Practice Modes: Free Play, One-Minute Changes, Transition Matrix.
